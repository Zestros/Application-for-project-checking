# Project Health

## Project Idea

**Project Health** is a command-line tool for checking Python projects.

The main goal of the project is to help students, beginner developers, and teachers quickly understand whether a project is well-organized and ready for presentation, publication, or further development.

The tool scans a project folder and checks important files, dependencies, tools, and project structure. After scanning, it gives a score, status, and recommendations.

---

## Main Features

Project Health can check:

- README file
- License file
- `.gitignore`
- Git repository
- Dependencies
- Python version
- Docker files
- Project configuration files

After checking, the program shows:

- project score from 0 to 100
- project status: Critical, Weak, Good, or Excellent
- detected technologies
- required tools
- available tools
- recommendations for improvement

## Competitors

There are similar tools, such as linters, test runners, and CI tools.

For example, linters check code style, and test runners check if tests work correctly.

However, Project Health is different because it checks the whole project structure, not only the code.

It gives a general report about the project condition and shows what should be improved.
